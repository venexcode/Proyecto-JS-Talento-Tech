# VNX SGT - Sistema de Gestión para Talleres Automotrices

Este proyecto es una página web promocional (landing page) desarrollada para presentar el software de gestión para talleres mecánicos **VNX SGT**.

## Propósito de la página
La página busca informar a dueños y administradores de talleres sobre los módulos del sistema (recepción, órdenes de trabajo, stock, facturación), sus planes de precios y permitirles solicitar una demo o contacto directamente a través de un formulario web.

## Tecnologías utilizadas
- HTML5 (Estructura semántica)
- CSS3 (Flexbox, CSS Grid y Media Queries para diseño responsivo)
- Google Fonts (Fuente *Titillium Web*)
- Font Awesome (Iconografía)
- Formspree (Procesamiento del formulario de contacto)
- YouTube Iframe (Incrustación multimedia)
